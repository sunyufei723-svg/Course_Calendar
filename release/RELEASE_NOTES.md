# Course Calendar — Windows 单文件版（2026-09-15）

下载并运行 `CourseCalendar.exe` 即可打开课表编辑界面，无需另装 Python 或项目依赖。本版在 Windows 11 x64 上构建；业务逻辑基于提交 `c10fada`，本次新增图标资源。

## 本版内容

- 从不同颜色的课程块识别课表，支持时间轴横向或纵向的网格截图；识别后可逐门修改或一键核对信息完整的课程。
- 教师与课程名之间即使没有被 OCR 输出空格，也会比较字框间距与同一行字宽、通常字间距。留白不明显时保留完整课程名供人工核对。
- 从课程说明中寻找“教”“楼”“场”等地点线索，拼接被 OCR 折行的教室名；相邻的同一课程时段合并为一条记录。
- 课程序号独立保存，可选择是否加入日历标题。多周课程导出为每周重复日程，缺课周从重复中排除；ICS 内含时区定义。
- 新增课表图标，显示在程序窗口和 Windows exe 上。

## 使用与限制

打开 exe，选择课表截图，核对第一教学周的周一以及课程、周次、时间和地点，完成核对后导出 `.ics`。默认日期是今天之前最近的周一，实际学期起点若更早请手动修改。

过小或模糊的截图可能无法可靠区分教师与课程名，也可能缺少课程全名、周次或教室；请在界面中核对后再导出。旧 JSON 不会自动迁移：文件需含 `include_course_code`，每门课程需含独立的 `course_code` 字段。在 iPhone 上可从系统“邮件”App 的 `.ics` 附件导入；也可先在 Mac“日历”中导入到 iCloud 日历。
